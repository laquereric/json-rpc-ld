# Cyborg Channel SHACL shapes — MOVED

The normative Cyborg Channel SHACL shape files (`envelope`, `canonical-record`,
`sync-intent`, `private-local`, `allowlist.template`) have moved to the
**osi-level-8** repository, which hosts the OSI Level 8 specification that
documents them (section 8, "Interface Contracts: The SHACL Shapes"):

> https://github.com/laquereric/osi-level-8 → `shapes/cyborg-channel/`

This plan document (`cyborg_app_jsonrpcld_channel_plan_v0.2.md`) refers to these
shapes as `shapes/cyborg-channel/…`; read the shape files in the osi-level-8 repo.
